Overview

A presentation system for Vale’s presentation room in the Edifício Hélio Ferraz, inside Porto de Tubarão, built by D2R Studios in partnership with Zor Design. A desktop app spreads images, videos and information about the port across three borderless screens, and is controlled by a second app on an iPad.

The project dates from 2012, was expanded in 2015 and was remade in 2019 for PC and Android with a better networking system (UNet). As far as I know, it is still in use today.

Technical deep dive

2012 version

Two people built the original. I was an intern at D2R in charge of the desktop version. Unity had no 2D tools back then, so I wrote my own sprite system. I was still a Unity beginner and didn’t know coroutines yet, so it ran on a speed variable inside Update. The Mac–iPad communication was built by the other developer, through a database.

2015 version

New files were added, and the iPad app was expanded to show more images per file, since it had no pagination. The PC version always loaded from the Resources folder: as long as images are named correctly, there is no need to touch level design or code. Add the files and generate a build.

2019 version

The biggest change, done in one month. I remade the tablet app from scratch using Unity’s modern mobile workflow, and gave the PC app a real networking system, leaving OnGUI behind. The project moved from a pre-Unity Hub version to Unity 2018.4.
