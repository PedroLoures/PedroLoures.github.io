Highlights

  • Wrote every level around a Greek myth: each part opens with a tale, then challenges the player to make it happen in code
  • Built the concept around the CS student I was helping: she loved Greek mythology, so every level retells a myth, to keep her motivated to finish

Overview

One of my teachers asked me to help Raphaela, a Computer Science student, build an educational programming game. She had less than six months left and hadn’t started the concept yet.

In our talks I realized she didn’t know where to begin, so I asked her what she liked. She told me about Greek mythology, so, to make the project more enjoyable for her and something she’d be proud of, I wrote every level based on Greek mythology stories. Before each part, the game tells a piece of a myth and challenges you to make it happen. To move on, players write code in Lua.

Technical deep dive

Running player code

The first challenge was finding a language that could be compiled from within C# in Unity at the time. I remembered that game mods are often written in Lua, which settled the search quickly.

Each challenge knows the output it expects. Anything that doesn’t produce it gets either a custom message or the compiler’s own error message.
